4. Explanation of API Components
🔹 API Endpoint
Example: GET /students

Full URL: http://localhost:3000/students

Each URL path is an endpoint that performs a specific action

🔹 Request
The client sends a request to the server

Example: curl http://localhost:3000/students

🔹 HTTP Methods
Method	Action	Example
GET	Retrieve data	Get all students
POST	Create data	Add new student
PUT	Update data	Change student info
DELETE	Remove data	Delete a student
🔹 Headers
Provide metadata about the request

Example: Content-Type: application/json

Tells the server the request body is in JSON format

🔹 Request Body (Payload)
Data sent with POST and PUT requests

Example:

json
{
    "name": "David",
    "age": 23,
    "course": "Engineering"
}
🔹 Response
Data returned by the server

Example:

json
{
    "success": true,
    "message": "Student created successfully",
    "data": {
        "id": 4,
        "name": "David",
        "age": 23,
        "course": "Engineering"
    }
}
🔹 HTTP Status Codes
Code	Meaning	Example
200	OK - Success	GET request successful
201	Created	New student added
400	Bad Request	Missing required data
404	Not Found	Student doesn't exist
500	Server Error	Something went wrong on server
🔹 API Documentation
Available at http://localhost:3000/api-docs

Explains all endpoints, methods, and example requests

Helps developers understand how to use the API
